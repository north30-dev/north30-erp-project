# 10-全量页面美化方案

- **文档目的**：在不更换技术栈、不引入新组件库的前提下，基于现有 Ant Design Vue 4 组件库对全量页面做一次系统性视觉升级，确立可长期复用的设计令牌、页面模板与编码规范。
- **适用范围**：`erp-frontend/src/` 全部页面与布局（登录页、主布局、工作台、系统管理各功能页，以及后续基础数据与业务模块页面）。
- **执行约束**：所有改动仅涉及前端；改造过程不改变任何业务逻辑、接口调用与数据流。
- **视觉基调**：高级感、克制的业务软件审美——白卡承载信息、低饱和中性色打底、单一品牌色点睛；杜绝装饰性元素堆砌（渐变大横幅、emoji 图标、彩色卡片背景等），避免"一眼 AI"。

## 2. 设计令牌（Theme Tokens）

### 2.1 色彩体系

全站只允许出现以下三个层级的色彩，新页面禁止自造色值：

| 层级 | 变量 | 亮色值 | 用途 |
|------|------|--------|------|
| 品牌深 | `--erp-brand-deep` | `#16324f` | 侧边栏、登录页品牌区、时间轴节点 |
| 品牌主 | `--erp-brand`（antd `colorPrimary`） | `#2f6fe4` | 主按钮、选中态、链接、焦点 |
| 中性底 | `--erp-bg-layout`（antd `colorBgLayout`） | `#f5f6f8` | 内容区背景 |
| 中性面 | antd `colorBgContainer` | `#ffffff` | 卡片、表格、输入框 |
| 中性线 | antd `colorBorderSecondary` | `#e2e5ea` | 卡片描边、分割线 |
| 文字 | antd `colorText` / `colorTextSecondary` / `colorTextTertiary` | antd 默认灰阶 | 正文 / 次要 / 辅助说明 |

**状态色**（仅用于业务状态，不用于装饰）：成功 `#0fa964`、警告 `#d48806`、错误 antd 默认。列表状态一律用浅色 Tag（蓝=进行中、绿=完成态、黄=待处理、红=异常），具体映射见第 6 节。

### 2.2 主题注册方式【部分完成 2026-11-12：theme.css 变量表 + ConfigProvider token 注入已交付；"现有页面硬编码色值收拢"未完成】

1. `App.vue` 中以 `ConfigProvider` 包裹根节点，通过 `theme.token` 注入 `colorPrimary: '#2f6fe4'`、`colorBgLayout: '#f5f6f8'`、`borderRadius: 6`；后续暗色模式只需在此切换 `theme.darkAlgorithm`，组件层零改动。
2. 自定义样式（布局、登录页、工作台）的颜色一律引用 CSS 变量，变量集中定义于新建的 `src/styles/theme.css`，`:root` 声明亮色值。
3. **硬约束**：新增/改造页面的 `<style>` 中禁止出现颜色字面量（`var(--*)` 与 antd token 除外）；此规则纳入代码审查与 AGENTS.md 前端约定。

### 2.3 圆角、间距、字号

- 圆角：组件统一 6px（token `borderRadius: 6`），自定义卡片 8px，禁止 12px 以上大圆角。
- 间距：遵循 8px 栅格——相关元素 8px、组件组 16px、区块 24px；页面内边距统一 16px。
- 字号：页面主标题 16px/600，卡片标题 14px/600，正文 14px，辅助说明 12px；禁止出现 20px 以上的大标题（工作台欢迎语除外，16px/600）。

## 3. 图标规范（防"AI 感"核心条款）

1. **唯一图标来源为 `@ant-design/icons-vue`**，按业务域固定映射，全站不得出现 emoji、自绘 SVG 图标、外链图片图标：
   - 工作台 → `AppstoreOutlined`；用户 → `UserOutlined`；角色 → `TeamOutlined`；菜单 → `MenuOutlined`；部门 → `ApartmentOutlined`；字典 → `BookOutlined`；配置 → `SettingOutlined`；审计日志 → `FileTextOutlined`；登录日志 → `LoginOutlined`；附件 → `PaperClipOutlined`；导入任务 → `CloudUploadOutlined`；编码序列 → `BarcodeOutlined`；个人中心 → `UserOutlined`；退出 → `LogoutOutlined`。
2. 菜单图标与页面标题图标保持同一映射关系（菜单种子数据中的 icon 字段按此表校准）。
3. 图标尺寸：菜单 16px、快捷入口容器 32px（图标 16px 居中于品牌色浅底圆角方块）。
4. 后续业务域新增时在本文档表格中登记后再使用，保证"一个业务域一个图标"。

## 4. 页面级改造方案

### 4.1 登录页（方案 A：左右分栏）【已完成 2026-11-12】

```
┌────────────────────────────────────────────┐
│ 左侧 55%：品牌区              │ 右侧 45%：表单区 │
│  深蓝渐变 #16324f → #2f6fe4   │  白底           │
│  Logo + North30 ERP          │  问候语标题      │
│  产品定位一句话               │  表单（无卡片）   │
│  3 条特性点（图标 + 短文案）    │  登录按钮        │
└────────────────────────────────────────────┘
```

- **品牌区**：背景线性渐变（品牌深 → 品牌主）；文案直接复用 README 定位——"销售接单 → MRP 运算 → 采购生产 → 财务凭证，业务财务一体化"；特性点固定三条（全链路一体化 / 库存精准管控 / 产品级成本核算），前缀用 antd 图标（`ApartmentOutlined` / `DatabaseOutlined` / `CalculatorOutlined`），非 emoji。
- **表单区**：去掉 `a-card`，白底直排表单；标题"欢迎登录"（16px/600）+ 副标题"请使用系统账号登录"（12px 辅助灰）；验证码图与输入框严格等高、加 1px 描边与 4px 圆角。
- **登录逻辑不动**：验证码刷新频控、失败刷码、错误码特判（18042/10001）等全部保留。
- **响应式**：`<768px` 隐藏品牌区，表单区居中（复用现样式）。
- 页面注释中的"基建期占位版"字样随本次改造移除。

### 4.2 主布局（AppLayout / AppSidebar / AppHeader）【已完成 2026-11-12（多页签按本节裁剪决定未实施）】

- **侧边栏**：`theme` 改为自定义深色（品牌深 `#16324f` 起的纵向微渐变，或纯色 `#16324f`）；Logo 行加 `AppstoreOutlined` 图标 + "North30 ERP"（14px/600），Logo 可点击回工作台；选中菜单项 = 品牌主半透明底 + 左侧 3px 品牌色内嵌条 + 白色文字。
- **顶栏**：白底 48px；左侧面包屑；右侧依次为——刷新当前页（`ReloadOutlined`）、全屏切换（`ExpandOutlined`/`CompressOutlined`）、用户下拉（`a-dropdown`：个人中心、退出登录），头像用角色首字圆形徽标（品牌主底白字），不用图片。06 F9 规划的"标签页"（多页签导航）**本期裁剪**：当前仅系统管理单一业务域、页面以列表为主，页签收益低；待业务单据与详情页场景出现后再评估，裁剪决定以本条为出处。
- **内容区**：背景 `colorBgLayout`，内边距 16px；页面白卡直接铺内容，卡片描边用 `colorBorderSecondary`（替代默认投影，更"业务软件"）。

### 4.3 工作台首页（第一期：纯前端）【一期已完成 2026-11-12；快捷入口说明文案待菜单数据源支持，二期 KPI/待办未实施】

- **路由与注册**：新建 `views/dashboard/index.vue`；在 `dynamicRoutes.ts` 中与"个人中心"同级固定注册（path `/dashboard`，不进菜单树）；`/` 重定向由"首个可见菜单"改为 `/dashboard`（menus 为空或页面缺失时回退首个可见菜单，逻辑保留）。此处是对 06 F9"静态路由仅保留 login/404"口径的**显式修订**：与现有 `/profile` 固定注册同构，不进菜单树、不产生导航项，不违背"静态路由仅保留登录页"的意图。
- **页面结构**（对应已评审示意图，Ant Design Vue 组件实现）：
  1. 顶部欢迎卡：`a-card`——"早上好，{用户名}"（16px/600）+ 副行"今天 {日期} · 上次登录 {时间} {IP}"（12px 辅助灰）；右侧"个人中心"次级按钮。
  2. 左侧主卡"快捷入口"：按当前用户菜单树动态渲染 `a-row`/`a-col` 网格（3 列），每项 = 图标方块（品牌浅底）+ 名称 + 一行说明；仅渲染 `menuType=菜单 && visible=显示` 的节点，无权限自动隐藏；数据直接取 auth store 已缓存的 menus，**不调用任何新接口**。
  3. 右栏"系统信息"卡：`a-descriptions`——系统版本、所属角色、上次登录时间、登录 IP（全部来自 profile 数据）。
  4. 右栏"建设进度"卡：`a-timeline`——系统管理（已完成）/ 基础数据 / 业务模块 / 报表与集成；节点状态随开发阶段手工更新，当前阶段加"当前"徽标。
- **二期预留**：KPI 概览与待办列表的位置在快捷入口卡上方预留注释占位；数据待各业务域提供 `countByXxx` 汇总接口后接入，届时可考虑聚合接口 `/api/dashboard/summary`（避免首页并发请求过多）。
- 空菜单账号：快捷入口区显示 `a-empty`"暂无可访问的功能模块"。

### 4.4 列表页统一模板（影响面最大）【未开始】

**复用现有三件套**（06 F0 已交付的 `components/AppSearchForm/`、`components/AppCrudModal/`），仅**新建 `components/AppPageContainer.vue`** 统一两卡结构（组件以 `App` 前缀命名，符合前端规范）：

```
搜索卡（a-card）：查询条件行 + [查询] [重置] | 右侧主操作按钮（新建/导出）
表格卡（a-card）：a-table（含状态 Tag 规范）+ 分页
```

- **操作按钮**：主操作（新建）用 `type=primary` 靠右；行内操作用 `a-button type="link"`，最多显示 3 个，超出收进"更多"下拉；删除类操作红色并二次确认（现有 `Modal.confirm` 用法保留）。
- **金额/数量列**：右对齐、两位小数、`font-variant-numeric: tabular-nums`；金额前缀 ¥。
- **状态 Tag 映射**（新增状态时在本文档登记）：蓝（`processing`）= 待审核/进行中/部分完成；绿（`success`）= 已审核/已完成/已入库；黄（`warning`）= 待处理/临期；红（`error`）= 已作废/超期；灰（`default`）= 已关闭/已删除。
- **表格细节**：`size="middle"`、`row-key` 必填、列宽合理分配避免横向滚动；空数据用 `a-empty` 默认样式。
- 既有 system 各列表页逐页套用此模板（不改查询与提交逻辑）。

### 4.5 弹窗 / 抽屉 / 详情页分工规范【未开始（现状约定维持）】

确立并延续现有代码已自然形成的约定——**弹窗管写、抽屉管读、详情页留给业务单据**：

| 载体 | 用途 | 现状 |
|------|------|------|
| `a-modal` | 全部**写操作**：新增/编辑（AppCrudModal）、重置密码、分配角色/菜单、上传、删除确认 | 10 处，已统一，维持 |
| `a-drawer` | 全部**只读详情**：审计日志详情、导入结果、用户详情 | 3 处，维持载体 |
| 独立详情页 | **预留模式**，本期不实施；业务单据（销售订单/工单等）详情需"头部摘要 + 明细表 + 操作记录"结构时启用 | 0 处 |

- **弹窗规范**（基本零改动，仅固化现状）：标题由 AppCrudModal 按 mode 自动拼接"新增 XX"/"编辑 XX"；提交期间 loading 防重复点击；失败保持打开、提示由拦截器统一弹出——现状已达标，禁止再引入新的写操作抽屉。
- **抽屉规范**：宽度按内容 560~720px，`destroy-on-close`；**内容排版重做**——现有用户详情抽屉的三段 `bordered` 描述表格观感生硬，统一改为"卡片分节 + 轻量键值行"布局（无表格边框，标签列等宽对齐，空值统一 `-`）；状态与枚举一律 Tag 渲染，禁止裸 ID/裸枚举值直接展示（后端未返回名称的字段显示 `-`，不展示 ID 加提示文案）。
- 表单布局 `labelCol` 统一 `{ span: 5 }`，必填项校验提示文案统一"请输入/请选择 XX"。

### 4.6 全局体验细节【未开始】

- 路由切换：`a-spin` 包裹内容区（或顶部 3px 进度条，二选一，倾向进度条）。
- 加载：表格 loading 用 antd 自带 skeleton/spin；按钮 loading 已统一。
- 消息：成功/失败提示统一走 request 拦截器与 `message`，文案不带句号。
- 404 页：居中 `a-result status="404"`，提供"返回工作台"按钮。
- 禁止项：除登录页品牌区外禁止使用渐变背景；禁止彩色卡片底色；禁止 emoji；禁止 20px 以上大字号标题。

## 5. 暗色模式（两步走）

**本期只做地基**（随本方案第 2 节一起交付）：颜色 token 化 + CSS 变量收拢 + "禁止硬编码色值"规范。**完整暗色模式延后**至业务模块成型后（D5+）实施，届时：`ConfigProvider` 切换 `theme.darkAlgorithm`、为品牌深/浅变量补暗色值、顶栏加切换开关（localStorage 记忆 + `prefers-color-scheme` 默认跟随）。地基打好后，暗色改造预期只涉及变量映射与少量自定义样式，不再全站排查。
